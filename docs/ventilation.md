# 차량 공조 자동 전환 정책 · 통합 수정

## 기준 상태와 제어권

- 주행 시작 시 Pleos에서 실제 내기순환 ON/OFF를 읽습니다.
- 출발 전 이미 ON이면 앱은 이를 운전자 기본 상태로 존중하고 자동 OFF 명령을 보내지 않습니다.
- 출발 전 OFF이고 정책 조건이 충족될 때 앱이 ON을 요청합니다. SET 성공과 실제 상태 재조회가 일치한 경우에만 앱 소유 전환으로 기록합니다.
- 차량에서 운전자가 직접 ON/OFF를 바꾸면 주기적 상태 조회로 화면을 실제 상태에 맞추고, 해당 주행의 자동 제어권을 포기합니다. 운전자 조작을 되돌리는 명령은 보내지 않습니다.

## 겹치는 위험의 처리

- 자동 전환 시작 조건은 시연 모델 기준으로 `APPROACH + POOR`가 확인되고, 차량이 현재 RECIRCULATION이 아니며 자동 전환이 켜져 있는 경우입니다. 공사 상태가 ACTIVE이면 별도의 공사 위험도 함께 추적합니다. 따라서 공사 정보가 UNKNOWN/ENDED여도 접근 지점에서 대기질이 POOR로 확인되면 대기질 보호 전환은 가능합니다.
- 앱이 내기순환을 켠 뒤에는 공사 구간 통과/공사 종료만으로 OFF 하지 않습니다.
- 대기 등급이 `POOR`이면 공사 구간을 통과했더라도 내기순환을 유지합니다.
- 공사 위험이 통과/종료로 해소되고 대기 등급도 `NORMAL`로 확인됐을 때만 출발 전 OFF 상태로 복원합니다.
- 공사/대기 정보가 UNKNOWN이면 복원 근거로 사용하지 않습니다.
- 짧은 시연용 타임아웃으로 위험이 남은 상태에서 자동 OFF 하는 동작은 제거했습니다.
- 자동 전환을 끄거나 운전자 조작/김 서림 우선이 감지되면 앱은 자동 제어권을 포기하며 임의 복원 명령을 보내지 않습니다.

## 차량 상태 반영 및 명령 검증

- 대시보드는 Pleos의 실제 내기순환 Boolean을 기준으로 `내기순환 중` / `기본 공조 중`을 표시합니다.
- 주행 중 1.5초 간격으로 상태를 조회해 차량의 직접 조작을 감지합니다.
- 앱 명령 중에는 폴링을 잠시 미루고, 명령 이전에 시작된 오래된 폴링 결과가 새 상태를 덮어쓰지 않게 합니다.
- SET 응답 직후 상태가 아직 반영되지 않을 수 있어 400ms 간격으로 최대 5회 재조회합니다. 최종 재조회까지 요청값과 다르면 실패로 남기며, 성공으로 간주하지 않습니다.
- SDK에서 읽는 값은 내기순환 ON/OFF 하나입니다. `기본 공조`는 이 Boolean이 OFF라는 UI 표기이며, 자동/외기/내부 팬 등 전체 HVAC 설정을 읽거나 복원한다는 뜻은 아닙니다.

## 검증

`sh scripts/test-ventilation.sh`는 Android SDK 없이 정책 테스트를 실행합니다. 이번 버전은 초기 ON 유지, 앱 소유 ON 후 공사 통과, 대기 나쁨 지속, 두 위험이 모두 해소된 뒤 복원, 운전자 개입, 김 서림 우선, 정보 불명, 반대 방향, SET 실패 재시도를 검증합니다.

## 현재 구현 범위와 남은 연동 경계

- 샘플 주행은 고정 시나리오를 사용하고, 실제 GPS 주행은 Pleos FusedLocation 위치와 연속 위치 변화로 진행 방향을 계산합니다.
- ITS 공사 후보는 서부간선도로 설명, 경로 구간 안의 좌표, 30m 이내 도로 중심선, 북행 또는 양방향 조건을 모두 만족해야 선택됩니다. 공사 좌표는 지점 근사값으로 사용하며 그 지점을 중심으로 30m 길이의 작업 구간을 만듭니다. 정책은 그 구간 100m 전 접근 단계부터 판단합니다.
- 실제 GPS 주행 시작 시 ITS와 에어코리아를 새로 조회합니다. 활성 공사 상태와 2시간 이내 PM2.5 등급을 `VentilationInputBridge`로 정규화해 GPS 위치·방향과 같은 공사 구간이 확인될 때만 `VentilationPolicy`에 전달합니다. 실제 GPS 주행이 활성화된 동안 환경 조회를 5분마다 갱신합니다.
- 정보 조회 실패, 오래된 대기 관측, 경로 바깥 GPS, 반대 방향, 불일치 구간은 자동 제어 근거가 되지 않습니다. 자동으로 켠 내기순환은 공사 위험이 통과/종료되고 대기질이 보통으로 확인된 뒤에만 복원합니다.
- 이 데모는 등록된 서부간선도로 GPX에 맵매칭하며, 목적지 기반의 임의 내비 경로는 아직 사용하지 않습니다. 공사 좌표는 API의 근사 지점이고 정확한 실제 작업 경계와 다를 수 있습니다.
- 앱은 Pleos SDK의 내기순환 Boolean만 사용합니다. 전체 공조 프로필을 스냅샷/복원하거나 운전자 입력 이벤트를 원자적으로 구독하는 기능은 별도 SDK 지원 확인이 필요합니다. 이 구현은 시제품이며 실제 도로에서의 사용을 위한 제품 검증은 별도입니다.
