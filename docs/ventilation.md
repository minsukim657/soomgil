# 숨길 공조 정책

자동 공조가 켜진 동안 활성 공사 구간 접근·통과와 초미세먼지 나쁨 이상은 각각 내기순환을 켜는 근거입니다. 하나라도 확인되면 내기순환을 요청합니다. 운전자가 직접 끄더라도 확인된 위험이 남아 있으면 다시 요청합니다. 김 서림 제거는 자동 공조보다 우선합니다.

위험이 없는 상태에서 운전자가 조작하면 새 선호 상태를 기억합니다. 자동 전환을 끄거나 정보 부족으로 판단을 보류하는 동안에도 운전자가 선택한 상태를 존중합니다. 위치와 대기 정보가 돌아오면 확인된 위험을 다시 평가합니다. 위험이 모두 해소된 경우 앱이 바꾼 공조만 운전자의 기준 상태로 복구합니다.

ITS와 에어코리아 조회는 각각 성공한 데이터를 사용합니다. 에어코리아 관측이 2시간을 초과하거나 15초 동안 새 GPS 관측을 받지 못하면 해당 정보는 확인 불가가 됩니다. Pleos FusedLocation을 등록된 서부간선도로 경로에 대조하며, ITS 공사 지점의 근사 위치와 주행 방향으로 접근과 통과를 판정합니다.

Pleos Vehicle SDK에서 내기순환 ON/OFF를 확인한 뒤 화면과 캐릭터 문구에 반영합니다. sh scripts/test-ventilation.sh에서 공사·대기질 각각의 전환, 두 위험이 해소된 뒤 복원, 운전자 조작 및 정보 단절 후 복귀 동작을 검증합니다.
