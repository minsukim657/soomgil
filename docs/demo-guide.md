# 숨길 시연 가이드

## 준비

1. Android Studio에서 Pleos Connect 에뮬레이터를 선택해 숨길을 실행합니다.
2. 기기가 여러 대라면 터미널에서 adb devices로 Pleos 기기의 ID를 확인합니다. adb -s <Pleos 기기 ID> forward tcp:8088 tcp:8088을 실행하고, 브라우저에서 http://127.0.0.1:8088/을 열어 둡니다. [Pleos Virtual Console 설정](https://document.pleos.ai/docs/connect/guide/getting-started/application-development/use-vehicle-emulator)
3. 콘솔의 Climate에서 내기순환을 Fresh로 맞춥니다. 앱의 차량 공조 상태가 **기본 공조 중**인지 확인합니다.
4. 상태가 바뀌지 않으면 앱의 **공조 연결 테스트 열기 → 내기순환 끄기 요청 → 요청**을 사용하고, 현재 공조 카드의 응답을 확인합니다. 콘솔이 연결되지 않으면 SDK 요청이 접수되더라도 차량 상태가 반영되지 않을 수 있습니다.

## 영상 촬영 순서

1. **문제 소개** — “초미세먼지와 도로 분진에 민감한 탑승자는 공사 구간에 들어가기 전에 외기 유입을 줄이고 싶습니다. 숨길은 차량의 위치와 주변 환경 정보를 함께 확인해 내기순환을 자동으로 전환합니다.”
2. **재현 가능한 샘플** — **공사 접근 · 대기 보통 → 이 조건으로 주행 시작**을 누릅니다. 접근 단계의 내기순환 ON과 통과 후 위험이 해소될 때의 OFF 복구를 공조 카드와 주행 기록으로 보여줍니다. 가상 주행은 자동 진행됩니다.
3. **대조 시나리오** — **공사 접근 · 대기 나쁨**으로 같은 절차를 반복합니다. 통과 후에도 대기질이 나쁨이면 내기순환을 유지하는 모습을 보여줍니다. 자동 전환을 켠 상태에서 운전자 공조 조작 버튼으로 끄면 다시 ON이 됩니다.
4. **실제 정보 연동** — 인터넷과 API 설정이 갖춰져 있다면 **실제 GPS·환경으로 주행 시작**을 누른 뒤 [서부간선도로 GPX](../demo/soomgil-seobu-demo.gpx)를 재생합니다. ITS 공사 정보, 인근 에어코리아 관측값, 차량 위치로 판단한 주행 단계를 보여줍니다. 대기질이 보통이어도 활성 공사에 접근하면 내기순환을 켜고, 통과 후에도 대기가 나쁘면 내기순환을 유지합니다.

화면에 표시되는 정보는 ITS 공사 지점과 인근 초미세먼지 측정소 관측값입니다. 개발 범위는 Pleos 에뮬레이터의 서부간선도로 등록 경로이며, 임의 목적지 경로로 확장하려면 경로 좌표를 제공하는 별도 연동이 필요합니다.

## 접수양식에 사용할 구현 설명

숨길은 도로 공사와 초미세먼지에 민감한 탑승자를 위한 Pleos Connect 앱입니다. 공사 정보와 인근 대기질을 조회하고 차량 위치와 진행 방향을 등록 경로에 대조합니다. 진행 중인 공사 구간에 접근하거나 대기질이 나쁨 이상이면 내기순환을 요청하고, 공사 구간을 벗어나 대기질 위험이 해소되면 앱이 바꾼 설정을 이전 상태로 복원합니다. 서부간선도로 시제품에서 ITS·에어코리아 실시간 조회, 에뮬레이터 GPS 이동에 따른 공사 구간 판별과 내기순환 ON을 검증했습니다. OFF 복구는 대기질 회복을 포함한 샘플 주행으로 재현했습니다.
